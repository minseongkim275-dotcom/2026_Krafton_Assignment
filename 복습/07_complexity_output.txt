=== 이중 반복문 실행 횟수 ===
n=0 -> 0
n=1 -> 0
n=2 -> 1
n=5 -> 10
n=10 -> 45
n=100 -> 4950
n=1000 -> 499500

=== 공식 검증 (실제로 세어본 값과 비교) ===
n=0: 공식=0, 실제=0, 일치=True
n=1: 공식=0, 실제=0, 일치=True
n=5: 공식=10, 실제=10, 일치=True
n=10: 공식=45, 실제=45, 일치=True
n=30: 공식=435, 실제=435, 일치=True

=== 절반씩 줄이기 반복 횟수 ===
n=1 -> 0
n=2 -> 1
n=3 -> 1
n=8 -> 3
n=10 -> 3
n=1024 -> 10
n=1000000 -> 19

=== 시간복잡도 퀴즈 ===
배열 인덱스 접근: O(1)
해시 테이블 평균 조회: O(1)
이진 탐색: O(log n)
선형 탐색: O(n)
병합 정렬: O(n log n)
퀵 정렬 평균: O(n log n)
버블 정렬: O(n^2)
삽입 정렬 최악: O(n^2)
모든 부분집합 완전탐색: O(2^n)
모든 순열 완전탐색: O(n!)
듣도 보도 못한 정렬: 모름
