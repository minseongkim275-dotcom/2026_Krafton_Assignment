=== 힙 push / pop ===
push 5 -> [5]
push 3 -> [3, 5]
push 8 -> [3, 5, 8]
push 1 -> [1, 3, 8, 5]
push 9 -> [1, 3, 8, 5, 9]
push 2 -> [1, 3, 2, 5, 9, 8]

꺼내는 순서 (정렬되어 나와야 함):
[1, 2, 3, 5, 8, 9]

=== 힙 정렬 검증 ===
[5, 1, 4, 1, 5, 9, 2, 6] -> [1, 1, 2, 4, 5, 5, 6, 9] (일치: True)
[1] -> [1] (일치: True)
[] -> [] (일치: True)
[3, 3, 3] -> [3, 3, 3] (일치: True)

=== 빈 힙에서 pop ===
IndexError 발생 (정상)

=== k번째로 큰 값 ===
[3, 2, 1, 5, 6, 4], k=2 -> 5
[3, 2, 3, 1, 2, 4, 5, 5, 6], k=4 -> 4
[1], k=1 -> 1
[1, 2], k=5 -> None

=== 정렬된 리스트 k개 병합 ===
[[1, 4, 5], [1, 3, 4], [2, 6]] -> [1, 1, 2, 3, 4, 4, 5, 6]
[[1, 2, 3]] -> [1, 2, 3]
[[], [1], []] -> [1]
[] -> []
